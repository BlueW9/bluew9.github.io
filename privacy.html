Privacy Policy

Last updated: October 24, 2026

1. General Principle

Our software development philosophy is built on respect for user privacy, digital independence, and the right to full control over one's own data.

2. No Network Connection

Software covered by this policy is designed to work locally, without an internet connection or any connection to external networks, and without creating remote communication channels.

3. No Data Transfer

The software does not send user data, files, or content to any third party. Data remains within the local storage scope defined by the design of each program.

4. No Cloud Services

The software does not rely on cloud servers, remote storage services, or external synchronization to process or store user data.

5. No Data Collection

Our design philosophy excludes collecting user data, tracking user activity, building user profiles, or running behavioral analytics.

6. Local Processing

The software's functions run locally on the user's device. Protection and encryption mechanisms, where available, are applied according to the technical specifications published for each project.

7. Artificial Intelligence and Training

The software covered by this policy does not rely on remote artificial intelligence services, and does not send user data to any party for the purpose of training or improving models.

8. Scope of This Policy

This policy expresses the principles adopted in the design of the software it covers. The technical characteristics of each project are stated in its official documentation, so that anyone can verify that the implementation matches these principles.

9. Review and Updates

Any changes to this policy will be published on this page, together with an updated revision date.

Core goal: software that works locally, with no external connections, no data transfer, and no reliance on cloud services.
