How to verify these apps

Every app is open source. Every release is built by GitHub Actions from the public code and signed with one permanent X Team key. Each repository also runs automated checks (CodeQL, mobsfscan and OpenSSF Scorecard) and shows the results in its Security tab.

Signing certificate SHA-256:
F4:D3:0E:85:23:91:17:AE:BC:35:55:43:6C:65:11:BC:A0:5E:E3:50:81:49:9A:4A:42:AE:B0:98:DC:1E:72:DA

To compare, run apksigner verify --print-certs app.apk on a downloaded APK. The SHA-256 must match the value above.
